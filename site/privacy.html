Privacy

A scan produces a judgement about a real person. Here is exactly what is read, what is kept, and who can see it.

01 / 05

What runs where

The scanner runs on the scanned person's own computer. It reads the Minecraft installation that is actually open, the jars in it, running processes, JVM arguments and Windows records of recently deleted files. It does not upload their files — only what it concluded about them.

The whole scanner is one open file. Anyone can read it before running it, and everyone should.

02 / 05

What is stored

Kept

  • The Minecraft name the moderator entered
  • The Windows computer name
  • Mod file names, sizes and hashes
  • The verdict and the reasons behind it
  • Which moderator ran it, and when

Never uploaded

  • Any actual file from the computer
  • Screenshots, key presses, browsing
  • Passwords, tokens or account details
  • The Windows account name — it is stripped out of every stored path
03 / 05

Who can see a scan

A scan belongs to exactly one server. Its moderators and that server's owner can read it. Another server cannot, no matter how many scans it has. AsyncAnalyzer staff can read scans for support and for the shared cheat intelligence described below.

A moderator can also produce a shareable link. That version drops the computer name, the folder path and the system notes, and keeps the verdict and its reasons — the part somebody accused of cheating is entitled to argue with.

04 / 05

What is shared between servers

File hashes of confirmed cheats and confirmed-good mods are pooled, so a cheat caught on one server is known on the next. A hash is a fingerprint of a file — not of a person, and it carries no name.

A pooled hash reaches every client, so a wrong one would be a permanent false accusation against a legitimate mod. Every contributed hash records which scan it came from, waits for a human before it counts, and can be revoked.

05 / 05

Accounts and removal

An account holds your name, your email if you gave one, and the avatar from the service you signed in with. Signing in with Discord or Google shares nothing back with them beyond the fact that you signed in.

To have a scan or an account deleted, ask the owner of the server it belongs to, or write to us through the project page.
