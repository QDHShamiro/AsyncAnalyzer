Know what is in your mods folder — and be able to prove it.

AsyncAnalyzer reads every mod on a Windows PC, works out what its code actually does, and writes a report a screenshare moderator can act on. It runs entirely on the machine: nothing is uploaded, nothing is installed, nothing is changed.

Run it — PowerShell 
powershell -ExecutionPolicy Bypass -Command "iex (irm 'https://raw.githubusercontent.com/QDHShamiro/AsyncAnalyzer/main/AsyncAnalyzer.ps1')"

No flags, no questions. It finds the Minecraft installations by itself, decides how deep to look, and tells you at the end what it could not check.

Why you can run this on your own PC
  • It only reads. No file is modified, moved or deleted. No program is installed and nothing is left running afterwards.
  • Nothing leaves the machine. The analysis is local. Team upload exists but is off unless a team turns it on, and it sends results — never your files.
  • You can read it before you run it. The whole scanner is one PowerShell file. Open the link in a browser and read it top to bottom.
  • It says what it could not check. A clean result only ever covers what was actually looked at, and the report lists the gaps next to the verdict instead of implying more.
  • It does not open anything. No windows pop up, no file explorer, no browser. It prints where the report is and stops.
What the report gives a moderator
  • One verdict, judged across mods, system, processes, the live game and the execution history together — not one number per file to add up by hand.
  • Every finding with its reasoning and the exact paths, hashes, process IDs and memory addresses behind it.
  • A coverage box naming what could not be checked, so nobody reads more into a clean result than it says.
  • Prints to PDF, so it can be attached to a ban appeal.
