What the detector actually gets right

AsyncAnalyzer scores Minecraft mods for cheat behaviour. These numbers are regenerated by CI on every push, so nothing here is hand-typed. The headline is deliberately the false-flag count, not accuracy: a detector that flags nothing scores well on accuracy and is useless.

Automation vs cheating

The line a legitimate mod never crosses

An auto-walk mod and a pathing cheat both move the player without input. The difference is in the bytecode: the mod drives the game's own input system, the cheat writes the movement packet itself.

Honest limits

What these numbers do not say

The cheat samples are reconstructions. Built from real open-source cheat client source (Meteor, Wurst, Baritone) and compiled by javac — this repo ships no cheat binaries. The constant pools come from a real compiler, so the structure is genuine, but a specific build of a paid client could differ.
ESP cannot be decided from bytecode. ESP and a mob-radar minimap perform the same operations. No model size recovers information that is not there, so it is surfaced for review instead of accused. That costs recall deliberately.
Zero means zero on these 186 libraries. It is evidence, not a guarantee. The corpus is in the repo and grows — the number is worth more the larger it gets.
A bigger model measured identically. Logistic regression, a neural network and gradient-boosted trees were compared under 5-fold cross-validation and scored the same. The behavioural features do the work, so the simple model ships.
